# Codex Automation Templates

These are sanitized examples of Codex automation prompts.

Public-safety notes:
- No real API keys, access tokens, passwords, private keys, or OAuth credentials are included.
- Local filesystem paths use placeholders.
- Client, repository, account, deployment, and thread identifiers are generalized.
- The prompts avoid publishing private URLs, internal links, customer names, exact folder structures, and unsupported business claims.

Use these as starting points, then adapt the placeholders for your own environment.
