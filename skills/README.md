# Skills

This folder contains the 10 skills from [`mnttnm/claude-skills`](https://github.com/mnttnm/claude-skills), adapted for use across Claude, Codex, and other coding agents that understand `SKILL.md` folders.

Compatibility changes:
- `SKILL.md` frontmatter is normalized to `name` and `description`.
- Codex metadata is added at `agents/openai.yaml`.
- Existing references, scripts, and assets are preserved.
- Packaged `.skill` archives and local machine files are excluded.

## Included Skills

- `dashboard`
- `harvest-feed`
- `interaction-design`
- `interface-grader`
- `lenny-research`
- `product-design-craft`
- `product-ui`
- `ui-autoimprove`
- `ux-patterns`
- `video-decompose`
